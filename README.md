💼 Frontend Developer Portfolio

A modern and responsive Frontend Developer Portfolio built with React.js and Tailwind CSS to showcase my skills, projects, education, and frontend development experience.

The portfolio is designed with a clean, responsive, and user-friendly interface and includes an integrated contact form powered by EmailJS.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/simranpanwar123/Frontend-Portfolio.git

2. Navigate to the project

cd Frontend-Portfolio

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will run on the local development server provided by Vite.

📩 Contact Form

The portfolio uses EmailJS to handle contact form submissions without requiring a custom backend.

This allows visitors to send messages directly through the portfolio’s contact section.

Make sure sensitive EmailJS configuration values are stored securely and are not committed as private secrets.
